# Ceddie（セディ）

DLコードとQRコードによるデジタル作品の配布を管理するWebアプリケーションです。

アイテム登録、コードの追加発行、回数・期限の管理、カード印刷などを扱います。PHP 8.3以降とSQLiteを基本構成としています。
